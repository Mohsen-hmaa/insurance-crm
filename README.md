# Insurance CRM

A desktop Customer Relationship Management (CRM) application built with Python to manage insurance operations and reduce repetitive administrative work.

## Features

- Customer and insurance policy management
- Insurance types and basic data management
- Marketer management and commission rules
- Commission calculations and reports
- Policy and collection data import from Excel
- Excel report generation and export
- Dashboard for operational overview
- Database management with SQLAlchemy
- Database schema migrations with Alembic
- Persian-language user interface and Jalali date support

## Technology Stack

- Python 3.13
- Tkinter
- SQLAlchemy
- SQLite
- Alembic
- Pandas and OpenPyXL
- Matplotlib
- jdatetime

## Project Status

Developed for practical insurance agency workflows, with a focus on reducing manual work and improving data management.

## Data and Privacy

This repository is intended for demonstration and portfolio purposes. Real customer records, insurance policies, databases, and private business files are not included.

## Installation

1. Install Python 3.13.
2. Clone or download this repository.
3. Create and activate a virtual environment.
4. Install the required dependencies.
5. Run the application using `python main.py`.

Detailed setup instructions and dependency configuration will be finalized before release.
